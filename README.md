🚀 Tinkering Lab Programs – Flutter & Dart

📌 About

This repository contains the complete Flutter & Dart Tinkering Lab programs developed as part of the User Interface Design using Flutter laboratory. It includes basic Dart programs, Flutter widgets, responsive UI, navigation, state management, animations, REST API integration, form validation, testing, debugging, and a mini Flutter application (LearnHub).

📚 Experiments Covered

1. Flutter & Dart SDK Installation and Basic Dart Programs
2. Flutter Widgets and Layouts (Text, Image, Container, Row, Column, Stack)
3. Responsive UI using MediaQuery and LayoutBuilder
4. Navigation using Navigator and Named Routes
5. Stateful & Stateless Widgets and State Management (setState & Provider)
6. Custom Widgets, Themes and Styling
7. Forms, Validation and Error Handling
8. Flutter Animations (Fade, Slide, Scale)
9. REST API Integration and Data Display
10. Widget Testing and Debugging Tools

🎓 Mini Project

LearnHub

A Flutter-based learning platform that helps students explore technology courses, access learning resources, internships, quizzes, and certificate information.

▶️ How to Run

1. Clone this repository.
2. Open the project in VS Code or Android Studio.
3. Run:
   flutter pub get
4. Connect an Android device or start an emulator.
5. Run:
   flutter run
